# Pre Entrega Automation Testing

Proyecto realizado con Python, Selenium y Pytest.

## Tecnologías utilizadas

- Python
- Selenium WebDriver
- Pytest
- Git y GitHub

## Funcionalidades

- Login automatizado en SauceDemo
- Validación de productos visibles
- Agregar producto al carrito
- Generación de reporte HTML

## Instalación

Instalar dependencias:

```bash
pip install selenium pytest pytest-html
```

## Ejecutar pruebas

```bash
python -m pytest -v
```

## Generar reporte HTML

```bash
python -m pytest -v --html=reporte.html
```
